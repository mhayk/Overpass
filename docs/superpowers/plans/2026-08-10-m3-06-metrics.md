# M3-06 — RED and domain metrics with Grafana dashboards — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every service exports RED and domain metrics over OTLP, two committed
Grafana dashboards render them, and the four alert rules — three of which cannot
currently fire — are proven by unit tests.

**Architecture:** Services push OTLP to the existing collector; Prometheus
scrapes only `otel-collector:8889`. A new `lib/go/telemetry` module installs the
tracer and meter providers for all three Go services; `feasibility` uses the
Python OTel SDK. RED is two shapes — semconv `http.server.request.duration` from
`otelhttp` for the two HTTP services, and one `outcome`-labelled histogram for
the three consumers.

**Tech Stack:** Go 1.25, `go.opentelemetry.io/otel` v1.45.0 + `otlpmetricgrpc`,
`otelhttp` v0.61.0; Python `opentelemetry-sdk` with `OTLPMetricExporter`;
OpenTelemetry Collector contrib 0.115.1; Prometheus + promtool; Grafana 11.4.0.

Design: `docs/superpowers/specs/2026-08-10-m3-06-metrics-design.md`.

## Global Constraints

- **Instrument naming: bake the unit into the name, leave the OTel `unit` field
  EMPTY.** Measured against the running collector. `overpass.allocation.duration_ms`
  with empty unit exports as `overpass_allocation_duration_ms_bucket`;
  `overpass.allocation.duration` with `unit: "ms"` exports as
  `overpass_allocation_duration_milliseconds_bucket` and orphans the committed
  alert. The semconv HTTP instrument from `otelhttp` is the one exception — it
  declares `unit: "s"` and `_seconds` is the name every other dashboard uses.
- **These three Prometheus names are fixed points**, because
  `deploy/prometheus/rules/alerts.yml` already references them:
  `overpass_outbox_pending_seconds`, `overpass_tle_age_hours`,
  `overpass_allocation_duration_ms_bucket`.
- **No explicit `service` label anywhere.** `resource_to_telemetry_conversion`
  already delivers `service_name`, `service_version`, `deployment_environment`
  and `job`.
- **Bounded label cardinality only.** `reason_code` (7), `satellite_id` (9),
  `policy` (4), `subject` (~6), `outcome` (5). Never `customer_id`,
  `request_id`, or `round_id`.
- **An unreachable collector is never a startup failure.** Existing rule from
  `telemetry.Setup`; it applies to the meter provider identically.
- Conventional Commits. Commit message bodies explain why and what was
  rejected.
- The final PR carries the `crosses-tracks` label — this touches all four
  service tracks plus `docs/decisions/`.

  ```go
      OutcomeTerminated   = "terminated"
      OutcomeDeadlettered = "deadlettered"

  // accumulates its Snapshot.
  func (m *Metrics) Bind(meter metric.Meter) error
  // Observe records one delivery's outcome and duration. Replaces AckAfter.
  func (m *Metrics) Observe(ctx context.Context, subject, outcome string, d time.Duration)

  ```

**Why `Observe` replaces `AckAfter`:** `AckAfter` is called at
`planner/internal/app/projector.go:186`, after the ack. The `Term` and `Nak`
paths at lines 145–165 `continue` before reaching it. A histogram hung off
`AckAfter` would therefore contain only successes — the wrong half for a metric
whose entire job is to show errors. `Observe` is called on **every** exit path.

  `http://localhost:9090`)

**The queries are extracted from the committed JSON, never restated.** A test
carrying its own copy of the query proves only that the test's query works —
which is precisely how `overpass_dlq_depth` survived review.

- [ ] **Step 1: Write the test**

```go
// Every panel in every committed dashboard must return data after seeded
// traffic. A panel naming a metric nobody publishes renders as "No data" and
// is invisible to every form of review except opening it.
func TestEveryDashboardPanelReturnsData(t *testing.T) {
	requireStack(t)
	for _, path := range dashboardFiles(t) {
		for _, expr := range panelExprs(t, path) {
			t.Run(fmt.Sprintf("%s/%s", filepath.Base(path), expr), func(t *testing.T) {
				result := queryPrometheus(t, expr)
				if len(result) == 0 {
					t.Errorf("panel query returned no series:\n  %s\n"+
						"either the metric is not published or the panel names it wrongly", expr)
				}
			})
		}
	}
}
```

`panelExprs` walks `panels[].targets[].expr`, including panels nested inside
rows, and skips Grafana template variables (`$__rate_interval` is substituted
with `5m` before querying).
